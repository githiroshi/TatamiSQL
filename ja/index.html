操作デモ

CORE FEATURES

マウス操作でSQLをもっと直感的に。

01

マウス操作でJOIN

テーブル名をダブルクリックして候補を選択。結合条件付きのJOIN句をSQLへ追加。

02

リストからカラム選択

SELECT * の「*」をダブルクリック。必要なカラムを選ぶと、SELECT句へ反映。

03

セルの内容をプレビュー

セルをダブルクリックすると内容を大きく表示。長文やJSONも見やすく確認。

04

テーブル名をグルーピング

共通する名前ごとにテーブルをまとめて表示。テーブルが多い環境でも探しやすく。
